# Decisiones iniciales de producto

## Plataformas

- El producto será multiplataforma.
- GitHub Copilot será un conector independiente.
- Cada plataforma podrá monitorizarse, ocultarse, silenciarse o impedir acciones.

## Seguridad

- Las credenciales permanecerán en el ordenador.
- El dispositivo enviará identificadores de acciones, no prompts completos.
- El modo predeterminado será solo análisis.
- Las operaciones destructivas no estarán disponibles desde el dispositivo.

## Hardware

- Core2 será el primer dispositivo de validación.
- El firmware mantendrá compatibilidad con la familia CoreS3.
- CoreS3 SE será el candidato principal para una pequeña serie comercial.
- La lógica de aplicación no dependerá de botones, batería o vibración concretos.

## Consumo

- No se mezclarán porcentajes de plataformas incompatibles.
- Los datos oficiales, calculados y estimados estarán diferenciados.
- Las plataformas sin datos fiables mostrarán información no disponible.

## Configuración

- La configuración avanzada se realizará en el ordenador.
- El dispositivo conservará únicamente ajustes cotidianos.
- Los proyectos y plantillas disponibles usarán listas explícitas de autorización.
