# Plan de implementación del MVP

## Fase 1. Base configurable

- Configuración de plataformas.
- Separación entre monitorización y visibilidad.
- Adaptador simulado.
- Detección inicial de GitHub Copilot CLI.
- Compilación Core2 y CoreS3.

## Fase 2. Panel local

- Aplicación de bandeja para Windows.
- Panel web local.
- Edición de plataformas.
- Proyectos favoritos.
- Perfiles Normal y Ahorro.
- Historial básico.

## Fase 3. Primeros conectores reales

- Codex.
- GitHub Copilot CLI.
- Un conector entre Qwen, Hermes u OpenClaw.

## Fase 4. Acciones rápidas

- Biblioteca de plantillas.
- Modo solo análisis.
- Selección de proyecto y plataforma.
- Confirmación y presupuesto.
- Seguimiento de la tarea.

## Fase 5. Alertas

- Consumo crítico.
- Caída rápida de cuota.
- Tarea terminada o fallida.
- Espera de autorización.
- Plataforma desconectada.

## Fase 6. Validación comercial

- Pruebas prolongadas con Core2.
- Prototipo CoreS3 SE.
- Base física con botones, encoder y LED.
- Instalador y actualizaciones.
- Revisión de certificaciones y costes.
